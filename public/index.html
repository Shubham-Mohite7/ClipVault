A simple way to keep useful text close

ClipVault is an online clipboard for the notes, links, and short pieces of text you want to find again. Save them in one place, then open the same vault on another device with your code.

Save snippets you use more than once

Keep reusable notes, links, and short text snippets together instead of searching through old messages or documents. Search your vault when you need something, then copy it into an email, form, or document. ClipVault is designed for everyday text, not passwords or confidential information.

Open your clipboard on another device

Create a vault code and enter it on the device where you need your saved text. There is no ClipVault account or password reset: the code is the only way back into the vault. Anyone who knows the code can access its contents, so store it privately and avoid using ClipVault for sensitive data.

Keep image and PDF attachments in your Drive

Connect your Google Drive to attach PNG, JPEG, GIF, or WebP images and PDF files. Attachments are saved in a ClipVault folder in your Drive. Each file can be up to 4 MB, and a vault can hold up to 50 files. ClipVault only manages files created through the app; other Drive files remain outside its access.

Use chat for everyday conversations

ClipVault Chat encrypts message contents in the participating browsers before sending them. The server stores ciphertext, but can still see participant codes and message timing. Vault codes are short access codes rather than strong passwords, so anyone who knows a code can access that vault’s chat keys. For that reason, don’t use ClipVault Chat for sensitive conversations.

Frequently asked questions

What can I save in ClipVault?

ClipVault is for reusable text such as notes, links, and short snippets. You can search, edit, and copy saved text. Do not store passwords, API keys, or other sensitive information.

How do I open my vault on another device?

Open ClipVault on the other device and enter the same vault code. The code is the only way to access the vault, so keep it private. Anyone who knows it can open the vault.

Can ClipVault recover a lost vault code?

No. ClipVault does not have a password reset or code recovery flow. Save your code somewhere private; without it, you cannot reopen the vault.

Can I attach images and PDF files?

Yes. Connect your Google Drive to attach PNG, JPEG, GIF, or WebP images and PDF files. Each file can be up to 4 MB, with up to 50 files per vault. ClipVault works with files created through the app in its own Drive folder.

Can ClipVault access all the files in my Google Drive?

ClipVault requests access to files created through the app. It creates a ClipVault folder in your Drive and does not access unrelated files elsewhere in your Drive.

How does ClipVault Chat encryption work?

Chat messages are encrypted in the participating browsers before they are sent, so the server stores message ciphertext rather than message text. The server can still see participant codes and message timing. Vault codes are not strong passwords, and anyone who knows a code can access that vault’s chat keys. Do not use ClipVault Chat for sensitive conversations.
